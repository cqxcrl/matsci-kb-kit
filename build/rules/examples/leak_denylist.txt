# 示例：**私有**专名 denylist。复制成 private/leak_denylist.txt 后填你自己的专名。
# （逐行一个正则，re.search 语义；# 开头为注释）
#
# 与公开那份（build/rules/leak_denylist.txt）的分工：
#   · 公开 —— 通用**形态**规则（家目录 / 用户名路径），谁 clone 都立刻有用，CI 靠它兜底；
#   · 私有 —— 你的源库**专名**清单。这份文件本身就是隐私，所以 gitignored。
#   两份在 scan_leaks() 里合并后一起跑；私有那份缺失时只告警不崩（clone 的仓库本来就没有）。
#
# 🔴 只列**真正的个人/身份标识**——不要放通用词（如「知识库」「Zotero」），
#    否则全部工具源码都会命中，扫描失去意义。
#
# 🔴 第三组是「不上传本地文献与隐私」这条红线的**机械化**：
#    真源里出现的具体课题名、项目卡名、文献卡 slug 一律不得进 kit，
#    必须被 scrub 成占位符；漏一个就在这里被拦成构建失败。
